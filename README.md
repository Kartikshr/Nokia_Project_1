<h1>Data Analysis Using Numpy and Pandas</h1>
<p1>This project includes end to end data analysis in the given four datasets and reaching to the conclusion containing the answeres to the questions asked:   

  1)Data Analysis Report[Netflix, Movies and TV shows]:   
  In this project report we are aimed to analyze the given dataset and firstly find all of the content populalrity trend and then answer few questions like content changed over the time and countries produced the   most shows.  

  2)Data Analysis Report[Airbnb Listings]:  
  In this project report we are aimed to analyze the given dataset and first to scraped the data and then find the answers to few questions i.e. Which area is most expensive and what are the features that leads     to higher price of the airbnb.  

  3)Data Analysis Report[Global Superstore Data]:  
  This project aims to analyze the Global Superstore dataset to simulate retail sales across various regions, identify the product category with the highest profit margin, and determine the top-performing regions.

  4)Data Analysis Report[World Happiness Report]:  
  This project aims to analyze the World Happiness Report dataset to compare well-being matrices globally, identify what factors correlates with happiness and if happiness changed over the time or not.
  </p1>
